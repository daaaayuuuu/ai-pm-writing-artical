# AI 产品文章与配图

通过多轮对话方式，把 AI 产品经理的项目经历、产品体验或研究材料，整理为适合微信「公众号」与「人人都是产品经理」发布的中文文章，并规划、生成和精修统一风格的封面及正文信息图。

## 这个 Skill 能做什么

- 讨论和筛选文章选题
- 确认标题、核心判断与文章结构
- 将多篇笔记整合成一篇完整文章
- 撰写、重写和打磨公众号文章
- 适配「人人都是产品经理」的内容表达
- 规划封面和正文配图
- 确定每张图片在文章中的放置位置
- 生成统一视觉风格的信息图
- 根据截图标注精修图片

## 适用场景

适合正在学习或实践 AI 产品经理工作，希望把以下材料整理成专业文章的人：

- AI 产品课堂笔记
- 项目经历与项目复盘
- AI 产品使用体验
- Agent、RAG、Prompt、模型评测等主题研究
- AI 产品设计、需求分析与竞品拆解

默认面向 AI／产品新人，不用于纯代码教程或与 AI 产品无关的写作。

## 工作方式

这个 Skill 默认采用「先确认，再写作，最后统一配图」的流程：

1. 理解材料与发布目标
2. 提供并确认选题
3. 确认文章标题
4. 确认核心判断和完整结构
5. 确认字数、语气与发布平台
6. 生成并修改文章
7. 制定文章配图地图
8. 生成和精修配图
9. 交付文章、图片与插图位置表

## 使用方法

在 Codex 中输入：

```text
$ai-pm-article-with-visuals
```

示例：

```text
$ai-pm-article-with-visuals

我有几篇关于 AI Agent 的课堂笔记，请通过多轮对话帮我确定选题，先不要直接生成文章。
```

## Skill 文件

Skill 位于：

```text
.agents/skills/ai-pm-article-with-visuals
```

核心内容包括：

- `SKILL.md`：主工作流和执行规则
- `references/writing-workflow.md`：文章写作流程
- `references/visual-workflow.md`：文章配图流程
- `references/quality-checklists.md`：交付质检清单
- `scripts/validate_article_package.py`：文章发布包检查脚本
- `assets/`：图标和视觉风格参考图
