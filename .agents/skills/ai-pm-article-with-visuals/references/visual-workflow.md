# 文章配图工作流

## 1. 先做配图地图

阅读全文后，列出每张图的四项信息：

| 字段 | 要求 |
|---|---|
| 放置位置 | 精确到某一章节及某一句之后 |
| 表达目的 | 读者看图后应理解的一个关系 |
| 视觉结构 | 层级、流程、循环、中心辐射、因果、对比或总结 |
| 精确文案 | 标题、卡片、标签、脚注逐字确定 |

相邻两张图不能解释同一个关系。图片不能代替正文中尚未讲清的论证。

## 2. 默认图片组合

标准长文默认五张：

1. 封面：文章对象、核心冲突和三个关键词。
2. 概念关系图：解释关键概念的层级或边界。
3. 运行机制图：解释流程、循环或工具调用。
4. 产品取舍图：解释架构、扩展方式或方案选择。
5. 核心结论图：解释成本、质量、指标或评估框架。

开头存在需要单独强调的判断时，可增加“开篇判断图”，放在核心判断之后、目录之前。

## 3. 默认视觉系统

- 背景：冰蓝白 `#F4F7FD`，叠加浅蓝细网格 `#D9E5F4`。
- 装饰：右上浅蓝半透明大圆、左下浅青半透明大圆，仅作为弱背景。
- 主文字：深海军蓝 `#071A35`。
- 强调色：亮蓝 `#2864E8`；辅助线蓝 `#5B83EA`。
- 次级文字：灰蓝 `#667791`。
- 卡片：白色圆角、浅蓝边框 `#CBD8EF`、轻阴影。
- 页脚：右下蓝色圆点加“大禹 AI 产品思考录”。
- 字体：现代无衬线中文；标题粗体，正文中等字重。
- 风格：克制、清楚、科技编辑感，不使用人物、3D 装饰、复杂图标或高饱和渐变。

使用 `../assets/style-reference-cover.png` 参考封面比例与标题层级，使用 `../assets/style-reference-body.png` 参考正文卡片、箭头、网格和署名。

## 4. 尺寸与排版

封面使用 `2048×872`。标题最多三行，整体水平居中；默认不放顶部标签。下方可使用三个关键词卡片和一句副标题。

正文图使用 `2048×1280`。标题置于左上，正文关系图居中，页脚署名置于右下。重要关系最多保留三至五个主要节点，避免移动端文字过小。

平级文字保持相同字号、颜色和字重。连接线必须连接到卡片边缘或中心锚点，水平线保持同一基线。

## 5. 选择制作方式

封面、氛围视觉或需要整体构图时，使用内置图片生成，并把风格参考图作为参考输入。

文字密集、箭头精确、层级复杂的信息图，优先使用 SVG、HTML/CSS、Canvas 或确定性绘图。生成后检查最终 PNG 尺寸与清晰度。

图片生成提示词至少包含：用途、参考图角色、画面结构、精确文字、色彩、尺寸意图、必须保持和必须避免的内容。所有图片中的文字都要用引号逐字列出。

## 6. 图片生成提示模板

```text
Use case: infographic-diagram
Asset type: 微信公众号正文配图
Input image: 仅作视觉风格参考
Primary request: 用一张图解释「核心关系」
Composition: 标题区 + 主关系区 + 必要脚注 + 右下署名
Text (verbatim): "逐项列出所有文字"
Color palette: 冰蓝背景、深海军蓝文字、亮蓝强调、白色圆角卡片
Constraints: 文字准确；箭头清楚；移动端可读；不添加额外标签或水印
Avoid: 人物、代码截图、3D 元素、红色批注、无关图标
```

## 7. 检查与精修

生成后按顺序检查：文字是否逐字正确、节点是否遗漏、箭头方向是否正确、线条是否对齐、层级是否清楚、缩小后是否可读、署名是否一致。

用户用红框或箭头标注修改时：

1. 读取标注指向的对象和动作。
2. 找到无标注原图作为编辑目标。
3. 把对象当成整体修改，例如“整体放大 1.25 倍并上移”。
4. 明确锁定所有未要求变化的元素。
5. 输出新版本并保留旧版；红框、箭头和批注不得进入成图。
